 The files are various versions of a binned average topography values.  The files 
 end with a code that defined the type and format of the file.  The code form is: 
 	_AB where 
 		A - either C or M.  C are color images.  M are greyscale images. 
		B - either G or L.  G file colors or greyscale shades are scaled based on  
 			global topography.  L file colors or greyscale shades are scaled based on the 
 			local topography ranges.  This provides greater contrast but cannot be compared 
 			to other binned images. 
 		 
 	There are several formats available: 
 		PNG (.png) - Standard PNG image formats 
 		JPEG (.jpg) - JPEG image formats with a world file
 		ENVI (_envi_xxx.img) - ENVI image format with a header file (_envi_xxx.hdr) 
 			ENVI files are map projected 
 		GeoTIFF (_xxx_mpt.tif) 
 			GeoTIFF files are map projected.

 		GeoJPEG2000 AUX XML (_xxx_mpj.jp2.aux.xml)
